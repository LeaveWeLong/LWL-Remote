# LWL-Remote

[![standard-readme compliant](https://img.shields.io/badge/readme%20style-standard-brightgreen.svg?style=flat-square)](https://github.com/RichardLitt/standard-readme)

C++ 实现的局域网远程桌面工具，用于在同一局域网内查看和控制另一台 Windows 机器的桌面。

## 背景

在局域网内（比如家里、办公室、实验室）经常需要临时看另一台机器的屏幕，或者帮别人操作一下。公网远程桌面工具要么需要中转服务器，要么配置复杂，要么对局域网内使用来说过于笨重。

LWL-Remote 的目标是做一个**轻量、纯局域网、无需公网依赖**的远程桌面工具。它只解决局域网内的场景，不追求跨公网、穿透 NAT 等复杂能力。

属于 [LeaveWeLong](https://github.com/LeaveWeLong/LeaveWeLong) 工作区下的子项目，独立成仓，独立构建。
